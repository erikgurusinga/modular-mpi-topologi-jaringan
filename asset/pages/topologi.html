Panduan Topologi

Star: Semua node terhubung ke satu node pusat (switch/hub). Mudah dikelola, jika pusat mati semua terputus.

Bus: Semua node terhubung ke satu kabel utama (backbone). Sederhana tapi rentan collision.

Ring: Setiap node terhubung ke 2 node tetangga membentuk lingkaran. Data mengalir satu arah.

Mesh: Setiap node saling terhubung langsung. Sangat redundan tapi mahal.

Tree: Kombinasi star bertingkat dengan hierarki. Cocok untuk jaringan besar.

Cara Menggunakan Simulator Topologi

  1. Tambah perangkat — klik perangkat di sidebar kiri, lalu klik pada canvas untuk menempatkannya.
  2. Hubungkan — pilih mode Hubungkan, lalu klik dua perangkat berurutan untuk menyambungkan kabel di antaranya. Koneksi yang melibatkan Smartphone, atau Access Point ke PC/Laptop/Smartphone, otomatis digambar sebagai jalur WiFi putus-putus — bukan kabel — sesuai cara kerja perangkat itu di dunia nyata.
  3. Lihat detail — klik perangkat pada canvas (mode Pilih) untuk melihat detailnya di panel kanan.
  4. Hapus — gunakan mode Hapus untuk menghapus perangkat/koneksi tertentu, atau tombol Bersihkan untuk mengulang dari awal.
  5. Undo — salah taruh, salah hapus, atau salah sambung? Klik tombol Undo (atau tekan Ctrl+Z) untuk membatalkan aksi terakhir.
  6. Zoom — gunakan tombol +/− di pojok kanan bawah canvas (atau scroll mouse / Ctrl dan +/−) untuk memperbesar/memperkecil area kerja, misalnya saat topologi sudah cukup ramai.
  7. Geser (Pan) — seret area kosong pada canvas (mode Pilih) untuk menggeser tampilan ke kiri/kanan/atas/bawah, berguna saat sudah di-zoom dan sebagian perangkat tidak terlihat. Klik "100%" di kontrol zoom untuk mengembalikan tampilan ke posisi & ukuran semula.
  8. Alamat IP — setiap perangkat otomatis dapat IP (terlihat di bawah namanya di canvas). Klik perangkat lalu ubah IP/Prefix-nya di panel kanan untuk mengatur subnet sendiri.
  9. Uji Koneksi — pilih mode ini, klik perangkat sumber lalu perangkat tujuan. Sistem memeriksa jalur fisik dan apakah keduanya satu subnet (kalau beda subnet, wajib lewat Router), lalu menganimasikan paket bergerak melewatinya.
  10. Simulasi Gangguan — pilih mode ini untuk mematikan perangkat atau memutus koneksi (klik lagi untuk menyalakan/menyambung kembali), lalu coba Uji Koneksi lagi untuk melihat ketahanan topologi terhadap gangguan.
  11. Analisis Topologi — panel di sidebar kanan ini otomatis menampilkan jenis topologi yang terdeteksi (Star/Bus/Ring/Mesh/Tree/dll) beserta statistiknya (jumlah node, link, degree, node pusat) dan status jaringan, dan ter-update sendiri setiap kali perangkat/koneksi ditambah, dihapus, atau di-undo.
  12. Analisis Jaringan — klik tombol ini untuk melihat kelebihan, kekurangan, dan solusi dari topologi yang sedang dibangun, ditambah kondisi jaringan yang sedang berjalan saat ini: perangkat mana yang mati, koneksi mana yang terputus (dari mode Simulasi Gangguan), dan apakah jaringan masih tetap saling terhubung meski begitu atau justru sudah terbelah jadi beberapa kelompok terpisah. Hasilnya muncul di tengah-bawah lembar kerja; menyalakan/mematikan perangkat atau memutus/menyambung koneksi lagi otomatis menutup hasil ini karena kondisinya sudah berubah.
  13. Contoh Topologi — klik salah satu contoh di sidebar (Star, Bus, Ring, Mesh, Tree) untuk memuatnya secara otomatis.
