Perangkat Jaringan

Klik perangkat untuk melihat detail

Cara Menggunakan Ensiklopedia Perangkat

  1. Pilih Perangkat — klik salah satu perangkat di daftar sebelah kiri untuk melihat detail lengkapnya.
  2. Deskripsi & Layer OSI — baca fungsi, deskripsi, dan posisi layer OSI perangkat tersebut di panel kanan.
  3. Fungsi Utama — pelajari daftar fungsi utama tiap perangkat pada bagian bawah panel.
  4. Tabel Perbandingan — gulir ke bawah untuk membandingkan spesifikasi antar-perangkat.
