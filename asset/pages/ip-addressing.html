Teori IP Address

Konsep dasar, kelas IP, dan subnetting

Apa itu IP Address?

IP Address (Internet Protocol Address) adalah alamat unik yang diberikan kepada setiap perangkat yang terhubung ke jaringan komputer. IP Address berfungsi sebagai identitas perangkat agar bisa saling berkomunikasi di jaringan.

IPv4 menggunakan format 32-bit yang ditulis dalam 4 oktet (kelompok 8-bit), dipisahkan oleh titik. Contoh: 192.168.1.1

Setiap oktet bernilai antara 0 - 255 (karena 8 bit = 28 = 256 kemungkinan).

Kelas IP Address

KELAS RANGE OKTET 1 DEFAULT MASK JUMLAH HOST PENGGUNAAN
A 1 — 126 255.0.0.0 16.777.214 Jaringan sangat besarDipakai ISP besar & perusahaan multinasional

D 224 — 239 — — MulticastUntuk kirim data ke banyak penerima sekaligus
E 240 — 255 — — EksperimenDicadangkan untuk riset, tidak dipakai publik

IP Private

IP Private digunakan di jaringan internal (LAN) dan tidak bisa diakses langsung dari internet:

  • Kelas A: 10.0.0.0 — 10.255.255.255
  • Kelas B: 172.16.0.0 — 172.31.255.255
  • Kelas C: 192.168.0.0 — 192.168.255.255

Apa itu Subnetting?

Subnetting adalah teknik membagi jaringan besar menjadi jaringan-jaringan yang lebih kecil (subnet).

Kelebihan
  • +Mengurangi lalu lintas jaringan
  • +Meningkatkan keamanan
  • +Penggunaan IP lebih efisien
  • +Memudahkan manajemen jaringan
Kekurangan
  • −Menambah kompleksitas desain, perlu perencanaan matang
  • −Salah alokasi bisa memboroskan atau menghabiskan alamat IP
  • −Menambah beban administrasi & dokumentasi jaringan

Cara Menggunakan Kalkulator IP Addressing

  1. Hitung — masukkan IP Address dan pilih Prefix Length (CIDR), lalu klik tombol Hitung.
  2. Hasil — lihat network address, broadcast, host pertama/terakhir, kelas, dan tipe IP di kartu Hasil Perhitungan.
  3. Representasi Biner — gulir ke bawah untuk melihat bentuk biner IP, subnet mask, dan pembagian bit network/host.
  4. Teori IP Address — klik menu ini di sidebar kiri untuk mempelajari konsep kelas IP, IP private/public, dan subnetting.
  5. Latihan Soal — klik menu ini di sidebar kiri untuk menguji pemahaman lewat kuis interaktif dengan pembahasan.
